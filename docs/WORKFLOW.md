# 制作和交接流程

1. 确定主题、观众和核心问题，先完成旁白；涉及政策的内容先核对官方来源。
2. 新建项目，修改品牌配置、题号和镜头文本；先明确六镜各自表达的信息。
3. 生成或导入配音，逐句记录实际时长；运行 prepare 后检查节奏和字幕断句。
4. 改 Scenes.tsx，保证文字、画面和旁白一致。模板动作可以复用，内容与关系不能只换标题。
5. 添加已有使用权的音乐，保存来源和许可；新音乐重新分析节拍。音效放进工程，记录来源、作者、许可和处理。
6. 用 still 检查每镜头中段、动作峰值和尾帧，再在 Studio 检查动态过程；检查标题、字幕、编号是否遮挡。
7. render 导出两版。完整播放，核对读音、语速、音效可闻性、片尾；另查黑帧、缺图、字幕、音画同步和尺寸。
8. 以三位编号-题名归档。保留源项目和脚本，上传前运行 check；私有业务素材留在本机忽略目录。

交接需要：项目目录、Node/npm 版本、字体、音乐授权记录、已测配音时长、画面/听检记录和输出位置。每位执行人使用自己的 .env；不要把密钥写进文档或分享截图。

现有示例来源于已完成的旧账簿扫描前准备内容。示例不含全部历史选题、公司内部资料或原视频资产库。
